# Security reports / Сообщения о безопасности

Please do not disclose exploitable details or personal data in public Issues. Use the repository's GitHub private vulnerability reporting feature when enabled. If it is unavailable, open a minimal Issue asking the maintainer to enable a private reporting channel, without an exploit, passwords, cookies or private messages. No private email address is published by this project.

Не публикуйте подробности уязвимости или личные данные в открытом Issue. Используйте private vulnerability reporting, если автор включил его в настройках GitHub. Если канал недоступен, запросите его включение без деталей эксплуатации.

Include the app/macOS/browser version, reproduction steps with synthetic data and expected/actual behavior. Maintainer: [petrou13](https://github.com/petrou13). Response times are not guaranteed.

The app is not sandboxed; current free binaries are ad-hoc signed and unnotarized. Local checks do not certify third-party website behavior. See [the security review](Release/SECURITY-AUDIT.ru.md) and [privacy](Release/PRIVACY.en.md).
