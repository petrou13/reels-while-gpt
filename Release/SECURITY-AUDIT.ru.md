# Проверка безопасности Reels While GPT 1.15

Дата: 8 октября 2026 года. Метод: ручной обзор исходников Swift/JavaScript, регрессионные проверки, проверка состава и подписи собранного приложения. Это проверка кода, не независимый пентест и не сертификат безопасности. Живой Instagram, реальный вход, AX установленного ChatGPT и Developer ID/TCC после нотарификации не проверялись автоматически.

## Что обнаружено и исправлено

| Наблюдение | Изменение | Практический эффект |
|---|---|---|
| Браузерный AX-обход запрашивал названия/описания у всех узлов, включая текст | Метаданные читаются только у кнопок. Поддеревья текстов, ссылок и полей не обходятся | Содержимое сообщений и значения полей не запрашиваются |
| Нативный обход запрашивал title/help/description у редактора | Редактор определяется только по роли, без метаданных и дочерних элементов; защищённые поля пропускаются | Меньше доступов к потенциально чувствительным данным |
| DOM-детектор использовал textContent кнопки | Только aria-label, data-testid и title; проверка с getter-ловушкой для textContent | Не извлекает текст дочернего содержимого |
| Заголовок текущей браузерной вкладки сохранялся в памяти для AX-сопоставления | Сопоставление по точному URL и однозначному AXWebArea; заголовки не читаются | Название чата не попадает даже в это временное состояние |

| Страница входа могла оставаться загруженной после скрытия | /accounts/ выгружается при закрытии независимо от keepLoaded | В памяти не удерживается закрытая форма входа; cookies сохраняются |

## Пароль и сохранённый вход — разные данные

Приложение не имеет собственного поля пароля, не обращается к значениям полей Instagram, document.cookie, cookie API экспорта или Keychain для паролей. Пароль вводится в официальную страницу Instagram, которая отправляет его в Instagram через HTTPS обычным механизмом сайта. macOS Passwords/автозаполнение может сохранять пароль по настройкам пользователя — это не хранилище утилиты.

Вход нельзя помнить совсем без сохранения данных: WebKit сохраняет cookies, токены сеанса и другие данные сайта. Эти токены чувствительны: они подтверждают авторизацию, хотя не являются паролем. Они сохраняются локально в стандартном persistent WKWebsiteDataStore приложения. Код не экспортирует их и не копирует из Chrome/Safari. Физические пути/формат управляются WebKit и зависят от macOS; вручную их приложение не определяет и не меняет. Шифрование всех файлов WebKit самим приложением не реализовано; защита зависит от macOS, прав пользовательского профиля и FileVault. Пользователь с доступом к профилю или вредоносный процесс того же пользователя может представлять риск.

WebKit хранит данные, созданные самим сайтом: cookies, localStorage/IndexedDB, кэш. Без исследования действительного поведения сайта нельзя обещать, что сайт никогда не записывает чувствительные значения в своё хранилище. Проверка подтверждает, что наша утилита сама не собирает/не записывает значения паролей. Абсолютное обещание «нигде ничего не сохраняется» было бы неверным.

## Данные и сеть

- UserDefaults: язык, переключатели, способ просмотра/источник, браузер, очищенный адрес Reels. NSWindow autosave: размер/позиция окон.
- Память во время наблюдения: URL ChatGPT и его AX/браузерные идентификаторы, состояния busy/idle/unknown, числовая диагностика. URL нужен для безопасного сопоставления конкретной вкладки. В журнал/настройки он не записывается.
- Диагностика остаётся в памяти. В буфер обмена попадает только по явной кнопке пользователя. После копирования другие приложения могут прочитать буфер обмена; не включайте его в публичные отчёты без просмотра.
- Нет телеметрии, аналитического SDK, собственного сервера, API-ключей, URLSession/fetch/XHR/WebSocket в коде утилиты, сетевого перехвата или выгрузки истории.
- Это не означает отсутствие сетевых запросов: Instagram/WebKit загружают сайт, видео и его сторонние ресурсы. Веб-сайт может использовать свои механизмы аналитики/рекламы. Правила main-frame навигации не являются блокировщиком всех subresource-запросов.
- Разрешения: AX для нативного детектора/браузерного fallback; Automation для выбранного браузера. Screen Recording, Input Monitoring, Full Disk Access, камера и микрофон утилите не нужны.

## Ограничения и оставшаяся проверка перед публичным выпуском

Текущая архитектура не использует App Sandbox из-за интеграции с другими приложениями. Hardened Runtime и разрешения TCC не заменяют sandbox. Сайт Instagram и другие приложения могут менять DOM/AX без предупреждения. Названия кнопок в AX — метаданные стороннего интерфейса; их содержимое контролирует тот интерфейс. Утилита не сохраняет произвольные метаданные и не включает их в отчёты.

Перед публикацией проверить на отдельном профиле macOS: официальный вход, сохранение входа после перезапуска, удаление встроенного входа, неизменность входа в браузерах; работу нового WKContentWorld, свайпов и hover; отказ/выдачу AX и Automation у Developer ID сборки; Gatekeeper на чистом Mac после скачивания. Нотарификация проверяет вредоносные компоненты, но не подтверждает корректность каждой функции и приватность стороннего сайта.
