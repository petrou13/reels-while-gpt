# Изменения

## 1.18

- Названия Instagram, Meta и Facebook убраны из собственного интерфейса. Справка, подсказки, статусы и команды входа используют «лента видео», «сервис» и «аккаунт» на русском и английском.
- Настройка адреса ленты свёрнута по умолчанию. URL, ограничение разрешённых сайтов и сохранение входа продолжают работать.
- Правовые сведения сохранены в документации. Страница стороннего сервиса может показывать собственное название и логотип.

## 1.17

- «Проверить детектор» использует выбранное подключение: приложение ChatGPT либо Safari/Chrome.
- Проверка браузера различает отсутствие браузера/вкладки ChatGPT, запрет Автоматизации macOS, недоступность JavaScript, успешный DOM-детектор, работающий Accessibility-fallback и неизвестное состояние.
- Результат содержит краткое объяснение и действия для устранения проблемы. Подробный обезличенный отчёт раскрывается отдельно; URL диалогов, сообщения, пароли и значения полей в него не входят.
- Распознаются короткие Stop/«Остановить», Interrupt и дополнительные подписи ответа. Повторение названия в нескольких атрибутах не мешает распознаванию. Отключённая кнопка и остановка записи/диктовки не считаются генерацией.
- Резервный браузерный детектор учитывает AXTextEntryArea. Ошибки JavaScript больше не исчезают из описания неизвестного состояния.
- Во время активного просмотра проверка обращается к исходной вкладке ChatGPT, а не к открытому окну Reels. При смене подключения старый результат сбрасывается.
- «Подключение» и «Технические» объединены; технический отчёт свёрнут по умолчанию.
- Уведомление о статусе Meta в РФ добавлено в настройки, справку, README, документы конфиденциальности и описание выпуска. Источник — перечень Минюста; подробности в LEGAL.ru.md.
- 245 автоматических проверок прошли локально. Живые сеансы браузеров, разрешения и авторизация требуют ручного прогона. Сборка остаётся тестовой, без нотарификации Apple.
