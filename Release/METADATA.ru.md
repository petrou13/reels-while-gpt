# Материалы страницы релиза

Instagram принадлежит Meta Platforms Inc., признанной экстремистской организацией; её деятельность по реализации Facebook и Instagram запрещена в Российской Федерации. [Перечень Минюста России](https://minjust.gov.ru/ru/documents/7822/).

Название: Reels While GPT

Краткое описание: Ваш маленький перерыв, пока ChatGPT думает.

Описание: Локальная утилита для macOS открывает собственное вертикальное окно Instagram Reels, пока ChatGPT готовит ответ, и скрывает его после завершения. Поддерживает приложение ChatGPT, Chrome и Safari. Позволяет открывать Reels вручную, переключать видео свайпом и перематывать текущий ролик. Компактная временная шкала может раскрываться при наведении мыши.

Требования: Apple Silicon, macOS 13 или новее. Для воспроизведения нужны интернет и доступ к Instagram. Instagram может потребовать вход. Для нативного детектора нужен Универсальный доступ; для браузера — Automation и, при DOM-режиме, разрешённый JavaScript from Apple Events.

Конфиденциальность: код утилиты не собирает пароль или сообщения. Вход Instagram сохраняется локальными cookies WebKit; его можно удалить в настройках. Сам сайт Instagram обрабатывает данные по своей политике.

Независимое приложение. Не связано с OpenAI или Meta и не является официальным клиентом этих компаний.
