# Reels While GPT

Ваш маленький перерыв, пока ChatGPT думает.

[English](README.en.md) · [Лицензия](LICENSE.ru.md) · [Конфиденциальность](Release/PRIVACY.ru.md)

Локальная утилита для **Apple Silicon, macOS 13+**: открывает собственное вертикальное окно Instagram Reels, пока ChatGPT готовит ответ, и скрывает после завершения. Поддерживает приложение ChatGPT, Chrome и Safari. Можно открыть Reels вручную, листать свайпом и перематывать ролик.

Автор: [petrou13](https://github.com/petrou13). Независимый проект, не связанный с OpenAI или Meta. Исходники доступны для некоммерческого использования по PolyForm Noncommercial 1.0.0; это source-available, а не OSI open source.

## Что умеет

- Автоматический просмотр во время ответа или ручное открытие Reels.
- Плавающее окно поверх полноэкранных приложений; перемещение и изменение размера.
- Свайп вверх переключает один ролик; перемотка находится под страницей Instagram.
- Компактная шкала может сворачиваться в тонкую полоску и раскрываться при наведении.
- Сохранение загруженной ленты для быстрого повторного открытия.
- Настройки звука, возврата к ChatGPT и языка — русский/английский.
- Браузерная картинка в картинке как альтернативный просмотрщик.
- Локальное сохранение входа Instagram и кнопка его удаления.
- Одна работающая копия приложения; понятный статус и отдельная диагностика.

## Установка

Версия **1.16** — бесплатная тестовая сборка: локальная ad-hoc подпись, **без Developer ID и нотарификации Apple**. Подписанный Apple выпуск подготовлен как будущий этап; платная учётная запись разработчика не нужна для чтения исходников и локальной сборки.

Архивы готовых приложений размещаются в [Releases](https://github.com/petrou13/reels-while-gpt/releases), когда опубликован соответствующий выпуск. Если выпуск ещё не создан, используйте сборку из исходников. Код в репозитории и наличие публичного выпуска — разные этапы.

1. Завершите старую копию через «Выход».
2. Распакуйте ZIP и перенесите `Reels While GPT.app` в удобную постоянную папку, например `~/Applications`.
3. macOS может заблокировать ненотарифицированное приложение. Если вы доверяете выбранной сборке, используйте стандартное «Всё равно открыть» в настройках конфиденциальности и безопасности, если macOS предлагает эту возможность. См. [инструкцию Apple](https://support.apple.com/102445). Не отключайте Gatekeeper/SIP глобально.
4. В «Подключении» выберите приложение ChatGPT или браузер и выдайте нужные разрешения.
5. В «Просмотре» выберите просмотрщик, откройте Instagram и войдите, если сайт этого требует.
6. Включите «Открывать Reels, пока ChatGPT готовит ответ» или нажмите «Открыть Reels» для ручного просмотра.

## Разрешения

**Универсальный доступ:** нужен для нативного ChatGPT и браузерного AX-fallback. Добавьте именно установленную копию приложения в «Системные настройки → Конфиденциальность и безопасность → Универсальный доступ». Кнопка в программе сначала предлагает перейти в настройки; сама по себе выдача доступа не включает наблюдение.

**Автоматизация:** нужна для управления выбранным Chrome/Safari через Apple Events. В браузере для DOM-детектора также может потребоваться «Allow JavaScript from Apple Events»: Safari — меню Develop, Chrome — View → Developer. Если JavaScript недоступен, применяется Accessibility-fallback, который может распознавать меньше состояний.

Утилите не нужны запись экрана, мониторинг ввода, полный доступ к диску, камера или микрофон. Не включайте лишние разрешения ради устранения ошибки.

## Конфиденциальность

Код не запрашивает значения паролей, текст сообщений или заголовки чатов. Нет собственного сервера, телеметрии или аналитического SDK. Детектор проверяет признаки кнопки остановки ответа; работа не требует ключей API и перехвата сети.

Чтобы помнить вход, WebKit локально сохраняет cookies/токены сеанса и данные Instagram. Это чувствительные данные авторизации, хотя не пароль. Введённый пароль обрабатывает официальный сайт Instagram; сам сайт может использовать собственные механизмы хранения и аналитики. Утилита не импортирует cookies Chrome/Safari и не экспортирует их разработчику.

В «Просмотре» есть «Удалить сохранённый вход в Instagram…». После подтверждения удаляются данные встроенного окна, но вход в Chrome/Safari не меняется. Подробности: [политика](Release/PRIVACY.ru.md), [проверка безопасности](Release/SECURITY-AUDIT.ru.md).

## Сборка и проверки

Нужен Xcode с macOS SDK; настройте инструменты и примите лицензию Xcode. Членство в платной Apple Developer Program для локальной сборки не требуется. Скрипт использует выбранный Xcode, Swift 5 mode и собирает arm64 для macOS 13+:

```bash
./build.sh
./Tests/run.sh
```

Для JavaScript-проверок нужен Node.js (в CI используется Node 24). Результат: `dist/Reels While GPT.app` и `dist/ReelsWhileGPT-arm64.zip`. Текущая локальная подпись — ad-hoc с Hardened Runtime. Лицензия и NOTICE включены в приложение.

218 локальных проверок прошли при подготовке версии 1.15; версия 1.16 добавляет оформление репозитория и лицензию без изменения логики. Сборка 1.16 и подпись проверяются отдельно. Проверки не подтверждают реальный вход, живую ленту Instagram или работу AX после изменения сторонних приложений. Перед публичным выпуском нужен ручной прогон на отдельном профиле macOS.

GitHub Actions проверяет код и собирает локально подписанный архив. Отдельный ручной workflow позволяет опубликовать **тестовый prerelease**, не требуя секретов Apple. Наличие workflow не означает, что он уже успешно выполнен. См. [публикацию без платного аккаунта](Release/GITHUB.ru.md).

## Ограничения

Instagram и ChatGPT могут менять DOM/Accessibility, из-за чего детектор или перелистывание потребуют обновления. Instagram может ограничить доступ или потребовать авторизацию. Программа не обходит ограничения сайта. Видео заполняет область без растяжения с небольшой обрезкой краёв. Браузерный PiP использует возможности браузера и может требовать нажатия.

Текущая архитектура не использует App Sandbox и не готова для Mac App Store. Сайт Instagram, его контент и бренды остаются под правилами правообладателей. [План Developer ID/нотарификации](Release/PUBLISH.ru.md) сохранён для будущего.
