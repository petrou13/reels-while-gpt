Исправления приветствуются по той же некоммерческой лицензии. Сохраняйте авторство и уведомления. Не добавляйте код с несовместимыми условиями или материалы, права на которые вам не принадлежат.

Describe the problem, the final behavior and relevant verification. Run `./Tests/run.sh` and `./build.sh` for behavior changes. Document manual checks separately from automated tests. Do not claim live Instagram/ChatGPT tests without performing them.

Do not add network interception, credential/cookie collection, telemetry, global security-setting bypasses, private ChatGPT/Instagram APIs or secret signing/notarization material. Keep permissions minimal. Never submit passwords, cookie dumps, account tokens, API keys or private screenshots.
